## What We've Built So Far

- **Header Component:** A sticky navigation bar complete with the Netflix logo, category links, search bar, notification bell, and user profile dropdown.
- **Banner & Rows:** Dynamic sections to showcase featured titles and horizontal movie lists.
- **Responsive Layouts:** Styled using CSS Modules to look great across different screen sizes.

---

## Tech Stack

- **React** with **Vite**
- **React Router** for page navigation
- **CSS Modules** for component styling
- **Material-UI Icons** for the interface icons
- **Axios** for handling API requests

## How to Run It Locally

If you want to test the project on your machine, just follow these quick steps:

1. Clone this repository to your local workspace.
2. Open your terminal in the project folder and run:
   ```bash
   npm install
   Set up your .env file with the required API keys.
   ```

Start the development server:

Bash
npm run dev
